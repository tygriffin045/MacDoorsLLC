# Mac Doors site

Static site for Mac Doors LLC, built to replace the coaching-template pages currently on macdoors.org.

Open index.html in a browser. Phone is (937) 408-2497. Owner is Jason McDonald. Service area is Columbus and surrounding areas. Email jason@macdoorsllc.com is still a stand-in.

To put this on Squarespace: create matching pages, upload the images, paste the copy, and put the phone in the header. Squarespace will not run this folder as the whole site unless you use a code-injection or developer-platform setup. Easier path: host these files on any static host and point the domain, or rebuild the same sections in the Squarespace editor.

Do not publish invented reviews. Add the owner name, license wording, and real job photos when you have them.
